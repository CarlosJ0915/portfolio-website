# Portfolio Website

My personal portfolio, showcasing my journey into software engineering and the projects I've built along the way.

Built with React + Vite.

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Project structure

```
src/
  components/   # small reusable pieces (Nav, ProjectCard, etc.)
  sections/     # page sections (Hero, About, Projects, Experience, Contact)
  data/         # content — edit projects.js and experience.js with your own info
  assets/       # images
```

## Editing content

- `src/data/projects.js` — add your projects here
- `src/data/experience.js` — add your courses/jobs/milestones here
- `src/sections/Hero.jsx` and `About.jsx` — edit the text directly
